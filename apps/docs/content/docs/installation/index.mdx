Salora Core is designed with flexibility in mind. Whether you are setting up a local development environment for contributing, or deploying the system to production, you can choose the architecture that best fits your infrastructure.



> Before starting any installation, ensure you have your environment variables configured. Copy `.env.example` to `.env` and configure your database credentials.

## Deployment Environments

Select the guide that matches your target environment. Salora supports edge deployments, containerized hosting, and local monorepo development.
